# CV en ligne – John Doe

Site vitrine d'un développeur web full stack, réalisé dans le cadre du devoir
**« Optimisez votre CV en ligne avec React.js »** (CEF).

Ce dépôt contient la partie site statique : HTML5, CSS3, Bootstrap 5 et
JavaScript vanilla. L'application React qui affiche le profil GitHub fera
l'objet d'un dépôt séparé.

## Pages prévues

- [ ] Accueil (bandeau plein écran + section « À propos »)
- [ ] Services
- [ ] Réalisations
- [ ] Blog
- [ ] Contact
- [ ] Mentions légales

## Lancement

Le site est statique : ouvrez `index.html` dans un navigateur, ou servez le
dossier avec `npx serve .`.
